# My GitHub Pages Site
Live at https://WilliamMorales1.github.io

Serves as my online professional porfolio and general information about what I'm working on.

Built with HTML, CSS (and SCSS), and JavaScript.

## Dependencies

- [Jekyll](https://jekyllrb.com/) with the `jekyll-theme-minimal` theme, run by GitHub Pages.
- [Typst](https://typst.app/) compiles `cv.typ` and `resume.typ` to PDF.
- Both run in the GitHub Actions workflow (`.github/workflows/cv.yml`); nothing to install for deploys. Local preview needs Ruby, Jekyll, and Typst.
